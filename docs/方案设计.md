# PromptVault（提示词弹药库）方案设计文档

> TRAE 好应用大赏赛 · 效率工具赛道 · 关键任务一【方案设计】

## 1. 问题定义

AI 时代的打工人每天都在"喂"AI：写代码的规则、写文案的模板、分析数据的指令、办公文档的套路。但这些提示词散落在聊天记录、备忘录、语雀收藏里——**用的时候找不到，找到的时候不是最新版，换个工具又要重写一遍**。

PromptVault 要解决的问题：**把个人最好的提示词，变成可检索、可复用、可迭代的资产。**

## 2. 目标用户

- AI 编程工具（TRAE/Cursor 等）深度用户：管理项目规则、系统提示词
- 内容创作者：管理文案模板、风格指令
- 知识工作者：管理办公/分析/翻译等高频指令

## 3. 核心功能（P0 全部实现）

| # | 功能 | 说明 |
|---|------|------|
| 1 | 提示词卡片库 | 标题/内容/分类/标签/颜色标记，卡片流展示 |
| 2 | 变量模板引擎 | `{{变量}}` 自动识别，点击即弹窗填空生成成品，一键复制 |
| 3 | 全文搜索 + 多维筛选 | 关键词搜标题/内容/标签；分类、收藏、标签筛选；多排序 |
| 4 | 版本历史 | 每次保存自动快照，可查看、回滚任意历史版本 |
| 5 | 使用统计 | 复制次数、最近使用时间，支持"最常用"排序 |
| 6 | 导入/导出/分享 | JSON 备份恢复；生成分享码，他人一键导入 |
| 7 | 预置精选库 | 内置 24 条编程/写作/办公/学习高质量提示词，开箱即用 |
| 8 | 命令面板 | Ctrl+K 快速搜索与跳转，全程键盘可达 |
| 9 | 数据看板 | 总数/分类分布/最常用 TOP，资产概览一目了然 |
| 10 | 主题与细节 | 亮/暗双主题、空状态引导、快捷键说明、本地自动保存 |

## 4. 技术方案

- **形态**：Web 应用（浏览器插件化体验，纯静态部署）
- **架构**：原生 HTML + CSS + JavaScript（零依赖、零构建，秒开秒用）
- **存储**：localStorage 本地持久化（数据不出本机，隐私安全），导出 JSON 可迁移
- **部署**：静态托管，公网可访问

### 数据模型

```js
prompt = {
  id, title, content, category, tags[], color,
  favorite: bool, useCount: int, lastUsedAt: ts,
  versions: [{ content, savedAt, note }],
  createdAt, updatedAt
}
```

## 5. 交互设计要点

- 首屏即卡片墙 + 顶部大搜索框，3 秒内完成"找→填→复制"
- 变量填空弹窗：识别 `{{xxx}}` 渲染表单，实时预览替换结果
- 卡片 hover 浮起 + 快捷操作（复制/填空/编辑/收藏/版本/删除）
- 删除二次确认；所有破坏性操作可撤销或可恢复
- 空状态给引导文案 + 一键导入预置库

## 6. 竞争差异

1. 不是"提示词合集网站"，而是**个人资产工作台**：版本历史 + 使用统计 + 模板引擎
2. 零依赖零登录，打开即用，数据本地
3. 预置精选库降低冷启动门槛
4. 分享码机制让"好提示词"可以流通
