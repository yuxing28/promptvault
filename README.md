# PromptVault · 提示词弹药库

> 把你最好的 AI 提示词，变成可检索、可复用、可迭代的资产。
> TRAE 好应用大赏赛 · 效率工具赛道参赛作品

**在线体验**：https://37jbtwf5c3peaoa9ws7.traesite.cn

## 这是什么

AI 时代的打工人每天都在"喂"AI：写代码的规则、写文案的模板、分析数据的指令。但这些提示词散落在聊天记录、备忘录里——用的时候找不到，找到的不是最新版。PromptVault 把它们变成你的个人资产库。

## 核心功能

- **提示词卡片库** — 分类、标签、颜色标记、收藏，卡片流一览
- **变量模板引擎** — `{{变量}}` 自动识别，点击填空即生成成品，一键复制
- **版本历史** — 每次修改自动快照，随时回滚
- **使用统计** — 复制次数、最近使用，找出你真正的"高频弹药"
- **资产看板** — 分类分布、最常用 TOP 5
- **导入 / 导出 / 分享码** — JSON 备份迁移，分享码一键流通
- **命令面板** — `Ctrl+K` 全程键盘可达
- **25 条精选预置** — 编程/写作/办公/学习/数据/营销/生活，开箱即用

## 技术特点

- 纯原生 HTML/CSS/JS，**零依赖、零构建、零登录**
- 数据 100% 存储于浏览器 localStorage，不上传任何服务器
- 单页面应用，秒开秒用

## 快速开始

无需安装，直接访问在线地址，或下载后用任意静态服务器打开 `index.html`：

```bash
python -m http.server 8080
# 打开 http://localhost:8080
```

## 快捷键

| 按键 | 功能 |
|---|---|
| `Ctrl+K` | 命令面板（搜索 / 快捷操作） |
| `N` | 新建提示词 |
| `/` | 聚焦搜索框 |
| `Esc` | 关闭弹窗 |

## 目录结构

```
promptvault/
├── index.html   # 页面结构
├── style.css    # 主题与样式（亮/暗双主题）
├── presets.js   # 25 条精选预置提示词
└── app.js       # 核心逻辑（状态 / 存储 / 渲染 / 交互）
```
